# Админ-панель для Ticket Bot

Веб-интерфейс для управления ботом поиска билетов, просмотра активных трекингов и отправки сообщений пользователям.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Отредактируйте файл `.env` и настройте параметры админ-панели:

```env
# Настройки админ-панели
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_secure_password   # либо ADMIN_PASSWORD_HASH (рекомендуется)
# ADMIN_PASSWORD_HASH=...             # python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('пароль'))"
SECRET_KEY=your_random_secret_key     # python -c "import secrets; print(secrets.token_hex(32))"
FLASK_HOST=127.0.0.1                  # Хост для запуска
FLASK_PORT=5000                       # Порт веб-интерфейса
# METRICS_TOKEN=...                   # опциональная защита /metrics
```

### 3. Запуск админ-панели

```bash
python admin_panel.py
```

Админка запускается через production WSGI-сервер waitress. Откройте браузер и перейдите по адресу: `http://127.0.0.1:5000`

## 🔐 Вход в систему

- **Логин:** `admin` (или значение из `ADMIN_USERNAME`)
- **Пароль:** значение `ADMIN_PASSWORD` (или пароль от `ADMIN_PASSWORD_HASH`)

⚠️ **Важно:** Пароля по умолчанию нет — без `ADMIN_PASSWORD`/`ADMIN_PASSWORD_HASH` админка не запустится. Смените пароль перед использованием в production.

Служебные эндпоинты: `/healthz` (проверка БД) и `/metrics` (Prometheus; при заданном `METRICS_TOKEN` требуется `Authorization: Bearer <token>`).

## 📋 Функционал

### Дашборд
- Общая статистика (активные трекинги, пользователи, поиски)
- Статус мест по всем трекингам
- Популярные станции

### Управление трекингами
- Просмотр всех активных трекингов с детальными параметрами
- Детальная информация о каждом трекинге (ID, маршрут, поезд, счетчик запросов)
- Удаление трекингов с синхронизацией с ботом (graceful shutdown)
- Включение/выключение heartbeat
- Настройка интервала heartbeat
- Уникальная идентификация каждого трекинга через ID

### Пользователи
- Список всех пользователей бота
- Профиль пользователя с историей трекингов
- Быстрая отправка сообщения пользователю

### Отправка сообщений
- Отправка сообщений от имени бота любому пользователю
- Поддержка HTML форматирования
- Ограничение длины сообщения (4096 символов)
- Логирование всех отправленных сообщений

### Логи администратора
- История всех действий администраторов
- IP-адреса, время, детали операций
- Аудит безопасности

### API endpoints
- `GET /api/statistics` - Получить статистику
- `GET /api/trackings` - Получить все трекинги
- `DELETE /api/tracking/<id>` - Удалить трекинг

## 🔧 Конфигурация

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `ADMIN_USERNAME` | Имя пользователя администратора | `admin` |
| `ADMIN_PASSWORD` | Пароль администратора (открытый текст) | не задан — вход запрещён |
| `ADMIN_PASSWORD_HASH` | Хеш пароля (приоритетнее `ADMIN_PASSWORD`) | — |
| `SECRET_KEY` | Секретный ключ Flask | генерируется временно |
| `FLASK_HOST` | Хост для запуска | `127.0.0.1` |
| `FLASK_PORT` | Порт веб-интерфейса | `5000` |
| `DATABASE_PATH` | Путь к базе данных | `data/ticket_bot.db` |
| `SESSION_TIMEOUT_MINUTES` | Авто-logout неактивной сессии | `60` |
| `LOGIN_MAX_ATTEMPTS` | Попыток входа до блокировки | `5` |
| `LOGIN_LOCKOUT_SECONDS` | Длительность блокировки входа | `900` |
| `IP_WHITELIST` | Список разрешённых IP через запятую | без ограничений |
| `METRICS_TOKEN` | Токен для `/metrics` | публичный, если не задан |

## ⚠️ Production рекомендации

1. **Задайте пароль/хеш и случайный ключ:**
   ```env
   ADMIN_PASSWORD_HASH=<хеш из generate_password_hash>
   SECRET_KEY=<hex-строка из secrets.token_hex(32)>
   ```

2. **Используйте HTTPS:**
   - Настройте reverse proxy (nginx)
   - Получите SSL сертификат (Let's Encrypt)

3. **Ограничьте доступ:**
   - Используйте firewall
   - Настройте whitelist IP
   - Рассмотрите basic auth на уровне nginx

4. **Мониторинг:**
   - Настройте алерты на ошибки
   - Мониторьте логи админ-панели
   - Отслеживайте подозрительную активность

## 📝 Примеры использования

### Отправка сообщения пользователю

1. Перейдите в раздел "Отправить сообщение"
2. Введите Chat ID пользователя
3. Напишите текст сообщения
4. При необходимости включите HTML форматирование
5. Нажмите "Отправить"

### Управление heartbeat трекинга

1. Перейдите в "Все трекинги"
2. Нажмите на иконку глаза для деталей
3. В разделе "Heartbeat настройки":
   - Pause/Start - включить/выключить
   - Измените интервал и сохраните

### Удаление трекинга

1. Найдите трекинг в списке
2. Нажмите кнопку удаления
3. Подтвердите действие
4. Бот получит сигнал об остановке и корректно завершит поток (graceful shutdown)
5. Трекинг удаляется из базы данных и in-memory хранилища бота

## 🆘 Troubleshooting

**Ошибка "Token must contain a colon"**
- Проверьте TELEGRAM_TOKEN в `.env`
- Токен должен быть в формате `123456789:AABBccDDeeFFggHHiiJJKKllMMnnOOpP`

**Не получается войти**
- Проверьте ADMIN_USERNAME и ADMIN_PASSWORD в `.env`
- Очистите cookies браузера

**База данных не найдена**
- Запустите основного бота для создания БД
- Или создайте директорию `data/` вручную
